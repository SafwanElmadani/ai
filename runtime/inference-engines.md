## llama.cpp
- llama.cpp is the core inference engine: a C/C++ library that runs GGUF-format models efficiently on CPUs and GPUs. 
- it can run multiple tasks in parallel
- https://github.com/ggml-org/llama.cpp

## vLLM
- an open-source inference engine for serving LLMs at scale
- It's the standard choice when you want to run a model behind an API endpoint serving many users at once
- vLLM is a Python project that loads safetensors straight from the Hugging Face Hub

## Unsloth Studio (fine tuning)
